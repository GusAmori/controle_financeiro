MEU CONTROLE DE GASTOS - APP PARA CELULAR (PWA)

O que faz:
- Salário por mês
- Gastos à vista
- Compras parceladas com a mesma descrição em todas as parcelas
- Quantidade de parcelas pagas e restantes
- Valor restante do parcelamento
- Gastos por categoria
- Saldo do mês
- Backup e restauração dos dados
- Funciona offline após instalado

COMO ABRIR NO COMPUTADOR
1. Extraia o arquivo ZIP.
2. Dentro da pasta, rode um servidor local simples. Exemplo com Python:
   python -m http.server 8080
3. Abra no navegador: http://localhost:8080

COMO USAR NO CELULAR
A forma mais simples é publicar a pasta em um serviço HTTPS (GitHub Pages, Netlify, Vercel etc.) e abrir o endereço no celular.
No Android/Chrome, use "Instalar app" ou "Adicionar à tela inicial".
No iPhone/Safari, use Compartilhar > Adicionar à Tela de Início.

IMPORTANTE
Os dados são salvos localmente no navegador/aparelho usando localStorage. Use o botão Exportar backup antes de limpar dados do navegador ou trocar de aparelho.
